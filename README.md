<details>
<summary><b>📐 how I work</b></summary>

<br/>

- **ADRs are the source of truth.** Design docs get a CLI, a review path, and a home — not a Confluence graveyard.
- **Golden paths, not guardrails-as-punishment.** If the paved road is slower than the shortcut, you built the wrong road.
- **Small repos.** Independent lifecycles, independent blast radius, independent ownership.
- **Taskfile over Make.** Every project, no exceptions, no tabs-vs-spaces war.
- **Agentic tooling is infrastructure now.** Treat skills, subagents, and MCP servers like you'd treat any other platform surface — versioned, tested, distributed.

</details>
